# Сравнение двух tmux.conf и расшифровка всех функций

## 1. Краткое отличие

| | Конфиг 1 (твой текущий, первый блок) | Конфиг 2 (приложенный файл) |
|---|---|---|
| Префикс | `C-Space` (Ctrl+Пробел). `C-b` отменён, остальные стандартные бинды на месте | Префикса нет: `unbind-key -a -T root` чистит всю таблицу root |
| Навигация между панелями | `h j k l` — только **после** префикса | `M-h/M-j/M-k/M-l` — сразу, Alt + клавиша |
| Новые окна / сплиты | `c C v s` — после префикса | `M-v M-s M-Enter` — сразу; `c C` оставил после префикса |
| Мышь | выключена | включена (`mouse on`) |
| Задержка после Esc | по умолчанию | `escape-time 0` (полезно для vim внутри tmux) |
| Копирование в буфер ОС | `set-clipboard on` (внутри tmux) | `y` копирует через `wl-copy` / `xclip` и выходит |
| Плагины | нет | TPM + resurrect + continuum (сохранение сессий) |
| Уникальное в конфиге 1 | переключение вложенной сессии `C-``, swap окон стрелками, мониторинг bell, `extended-keys` | перезагрузка конфига `M-r`, сессии `M-s`, окна `M-1..9`, ресайз панелей `M-Shift+стрелки`, поиск в копировании `M-/ M-?`, kill-pane/window/session, detach |

## 2. Что значит `-n M-n`

- **`-n`** — привязать клавишу в **таблице root** (режим без префикса). Клавиша срабатывает **сразу**, без нажатия префикса. Без `-n` tmux сначала ждёт префикс (в конфиге 1 — `C-Space`), и только потом саму клавишу.
- **`M-`** — модификатор **Meta**. В терминалах это обычно **Alt** (на macOS — Option). `M-n` = Alt+n, `M-S-Left` = Alt+Shift+СтрелкаВлево, `M-1` = Alt+1.

**Почему в конфиге 1 нет `-n`:**
В конфиге 1 всё построено на префиксе `C-Space`: нажимаешь `C-Space`, отпускаешь, а потом `h`, `c`, `v` и т.д.

**Почему в конфиге 2 `-н` почти везде:**
Конфиг 2 намеренно убирает префикс (`unbind-key -a -T root`) и вешает почти все функции на Alt через `-n`, чтобы работать «в один нажатие» без префикса.

## 3. Разбор функций конфига 1

Цвета и терминал:
- `default-terminal "tmux-256color"` — 256 цветов для приложений внутри tmux.
- `terminal-features ',xterm*:RGB'` — настоящий цвет (truecolor) для терминалов xterm*.

Префикс:
- `unbind C-b` / `set -g prefix C-Space` / `bind C-Space send-prefix` — префикс Ctrl+Пробел вместо Ctrl+B.

Панели (после префикса):
- `h j k l` — перемещение между панелями влево/вниз/вверх/вправо (вим-стиль).

Окна и сплиты (после префикса):
- `c new-window -a -c "#{pane_current_path}"` — новое окно после текущего в той же папке.
- `C new-window -c "#{pane_current_path}"` — новое окно в той же папке.
- `v split-window -h` / `s split-window -v` — разделение окна по горизонтали/вертикали в той же папке.

Режим копирования:
- `mode-keys vi` — вим-клавиши в копировании.
- `v` / `V` / `C-v` / `y` — начало выделения, строка, прямоугольник, копировать.
- `allow-passthrough on` / `set-clipboard on` — передача буфера обмена и скопированного текста наружу.
- `mode-style 'fg=#a7d8b0'` — цвет строки режима копирования.

Окна:
- `base-index 1` — нумерация окон с 1, не с 0.
- `renumber-windows on` — авто-перенумерация после закрытия окна.
- `automatic-rename on` / `automatic-rename-format '#{b:pane_current_path}'` — имя окна = имя папки.

Статус-строка и оформление:
- `status-position bottom`, `status-justify left`, `status-style 'bg=default'`.
- `status-left ' #S '` — сессия слева, цвет `#e1ffe5`.
- `pane-border-lines single` / `pane-border-style` / `pane-active-border-style` — окраска границ панелей.
- `window-status-*` — стиль неактивных/активных окон в строке статуса.

Вложенная сессия (C-`):
- Первая часть (`-T root`) — включает «режим выключения»: префикс отключается, ключевая таблица `off`, цвета приглушаются, отменяется режим копирования.
- Вторая часть (`-T off`) — та же клавиша `C-`` возвращает всё обратно.

Другое:
- `bind -r Left/Right swap-window ...` — перестановка окон соседними стрелками (с повтором при удержании).
- `monitor-bell on` / `bell-action other` / `window-status-bell-style` — сигнал о звонке в других окнах.
- `extended-keys on` / `extended-keys-format csi-u` — правильная передача модифицированных клавиш (Ctrl/Alt/Shift + клавиша) программам внутри tmux.

## 4. Разбор функций конфига 2

Цвета и терминал — такие же, как в конфиге 1.

Глобальные настройки:
- `unbind-key -a -T root` — сбросить все стандартные бинды без префикса, чтобы Alt-сочетания не конфликтовали с встроенными клавишами tmux.
- `pane-border-lines single` — одинарные линии границ.
- `base-index 1` / `pane-base-index 1` — нумерация окон и панелей с 1.
- `renumber-windows on` — авто-перенумерация окон.
- `mode-keys vi` — вим-клавиши в копировании.
- `mouse on` — мышь: переключение панелей, ресайз, прокрутка.
- `escape-time 0` — убрать задержку после Esc (vim внутри tmux работает отзывчивее).
- `history-limit 2000` — история буфера в строках на панель.

Бинды без префикса (`-n` = Alt + клавиша, сразу):
- `M-r` — перезагрузить конфиг без перезапуска tmux.
- `M-s` — дерево сессий для переключения (`choose-tree -s`).
- `M-1 … M-9` — быстрое переключение на окно по номеру.
- `M-h/M-j/M-k/M-l` — навигация между панелями стрелками в вим-стиле.
- `M-v` / `M-s` — сплит окна по горизонтали/вертикали в той же папке.
- `M-Shift+Left/Right/Up/Down` — изменить размер активной панели (5/5/3/3 строк/столбцов).
- `M-Enter` — новое окно.
- `M-c` — закрыть текущую панель.
- `M-q` — закрыть текущее окно.
- `M-d` — отсоединиться от сессии, оставив её запущенной.
- `M-Q` — завершить сессию с подтверждением.

Окна (с префиксом, как в конфиге 1):
- `c` / `C` — новое окно после текущего / в той же папке.

Режим копирования (вим-бинды):
- `v` — начать выделение.
- `y` — скопировать в буфер обмена системы (`wl-copy` для Wayland, `xclip` для X11) и выйти.
- `M-/` — поиск вниз в режиме копирования.
- `M-?` — поиск вверх в режиме копирования.

Плагины (TPM):
- `tpm` — менеджер плагинов.
- `tmux-resurrect` — сохранять и восстанавливать сессии.
- `tmux-continuum` — автосохранение сессий.
- `continuum-restore on` — восстанавливать сессию при запуске.
- `continuum-save-interval 15` — сохранять каждые 15 минут.
- `run '~/.config/tmux/plugins/tpm/tpm'` — запуск TPM (обязательная последняя строка).

Оформление — такое же, как в конфиге 1 (статус-строка, границы панелей, стили окон).

## 5. Итог

Конфиг 1 — классический «с префиксом C-Space», подходит, если ты не хочешь, чтобы Alt-комбинации перехватывались tmux вместо программ (vim, оболочка). Конфиг 2 — «без префикса, всё на Alt», удобнее для быстрой работы, но требует `unbind-key -a -T root`, иначе встроенные бинды tmux будут мешать.

Если хочешь совместить: возьми базу конфига 2 (мышь, escape-time 0, плагины, удобные Alt-бинды), но оставь `c C v s` с префиксом, если не хочешь перебивать мышью или другими программами.
